# Deadline Dash: The Missing USB

Deadline Dash is an interactive branching narrative game built with
Twine and the Harlowe story format.

The player must recover a missing USB drive and submit an assignment
before a deadline while navigating choices across the University of
Waterloo campus.

## Play

[Play Deadline Dash](YOUR-GITHUB-PAGES-LINK)

## Features

- Branching narrative with multiple decision paths
- Five possible endings
- Player state tracking
- Time and energy management
- Dynamic story outcomes based on previous decisions
- Custom responsive CSS interface
- Replayable story structure

## Technologies

- Twine 2
- Harlowe 3
- HTML
- CSS
- JavaScript

## Game Mechanics

The story tracks several player variables:

- Energy
- Remaining time
- Clues discovered
- Kindness
- USB recovery
- Cloud backup
- Coffee
- Snacks

Earlier decisions can change the options and outcomes available later
in the story.

## Running Locally

Clone the repository and open `index.html` in a modern web browser.
